# BALLISTIC EDGE

Играбельный браузерный vertical slice сверхскоростной 360° tunnel-racing игры с roguelike-сборками и трассами, которые генерируются из музыки.

## Запуск

```bash
npm install
npm run dev
```

Vite откроет локальную версию на `http://localhost:5173`. Production-сборка:

```bash
npm run build
npm run preview
```

Тесты:

```bash
npm test
```

## Серверная библиотека музыки

Чтобы добавить треки в выпадающий список игры, положите MP3, WAV, OGG, M4A, AAC, FLAC или WebM-файлы в `dist/assets/music/`, затем запустите:

```bash
npm run music:sync
```

Команда безопасно переносит новые файлы в `public/assets/music/`, даёт им стабильные имена и обновляет `manifest.json`. Она также автоматически выполняется перед `npm run dev` и `npm run build`, поэтому содержимое каталога не пропадёт при очистке `dist` во время сборки.

Каталог намеренно хранит уже импортированные версии. Чтобы удалить старый трек, удалите его одноимённые копии из `public/assets/music/` и `dist/assets/music/`, затем снова выполните `npm run music:sync`. `dist` одновременно служит входящей папкой и результатом последней сборки, поэтому оставшаяся там копия иначе будет импортирована повторно. Для устойчивой работы браузера файлы крупнее 48 МБ и треки длиннее 3 минут не принимаются; в заезде используются первые 108 секунд выбранной композиции.

Музыка и трасса выбираются независимо: серверный трек или локальный аудиофайл задаёт BPM и ритмический профиль, а карточки маршрутов — геометрию и уровень опасности.

## Управление

- `A / D` или стрелки — движение по внутренней окружности тоннеля.
- `Space` или `Shift` — boost; расходует Flux и нагревает реактор.
- `S` или стрелка вниз — форсированное охлаждение с потерей скорости.
- `F`, `Enter` или левый клик — оружие.
- `Q` или `E` — активная способность.
- `1 / 2 / 3` — выбрать новый roguelike-модуль прямо во время движения.
- Все клавиши можно переназначить в `CFG // SETTINGS`; основная и дополнительная раскладки сохраняются локально.

## Что уже реализовано

- Three.js/WebGL-трасса на Catmull–Rom оси с parallel-transport кадрами и 360° wall ride.
- Фиксированная симуляция 120 Гц и swept-проверка событий по дистанции, чтобы столкновения не пропускались на высокой скорости.
- Три визуально и механически разные трассы: Aurora Spine, Solar Rupture и Null Cathedral, каждая с собственной иллюстрацией маршрута.
- Boost, Flux, heat, forced vent, cooling, shield, near-miss и ритм-комбо.
- Три оружия, три активные способности, разрушаемые мины/дроны и AI-призраки соперников.
- Девять roguelike-модулей; два выбора в течение каждого заезда без остановки музыки или симуляции, с HUD установленных модулей.
- Постоянный гараж и рекорды в `localStorage`.
- Встроенный Web Audio техно-секвенсор.
- Загрузка локального MP3/WAV/OGG: RMS и частотные полосы анализируются до старта, BPM и beat offset оцениваются по onset-пикам, а build/drop/break/fill-переходы управляют поворотами, структурными кольцами и паттернами препятствий. Аудиофайл не покидает браузер.
- Музыкальные half-wall, twisted blades, вращающиеся cross-spiral, mine weave, ворота и предупреждающие маркеры с детерминированной раскладкой по битам.
- Bloom, музыкальный emissive-пульс, speed streaks, FOV boost, controlled RGB shift и режим уменьшенных вспышек.
- Адаптивный HUD и сенсорное управление.
- Сохраняемые настройки master/music/SFX, mute, трёх уровней качества рендера, bloom/RGB/camera shake, безопасных вспышек и полного переназначения клавиатуры.

## Архитектура

- `src/audio/AudioEngine.ts` — локальное декодирование, анализ и синтетический трек.
- `src/game/track.ts` — детерминированная генерация оси, frames и событий.
- `src/game/Game.ts` — симуляция, столкновения, бой и Three.js-рендер.
- `src/core/types.ts` — трассы, loadout и каталог upgrades.
- `src/main.ts` — UI, гараж, сохранение и жизненный цикл забега.
- `src/settings/SettingsStore.ts` — валидация, миграция и локальное хранение настроек звука, графики и управления.

Текущая версия — однопользовательский web vertical slice с тремя AI-призраками. Настоящий сетевой multiplayer требует authoritative WebSocket-сервера, синхронизации input/snapshots и отдельного правила для локальных MP3; игровая симуляция уже использует детерминированные seed и track-space state, чтобы эту часть можно было добавить без переписывания ядра.

## Production deployment

Игра является статическим Vite-приложением. Содержимое `dist/` можно публиковать напрямую; пример Nginx-конфигурации для `bullet.xedoc.ru` находится в `deploy/nginx.conf`. Конфигурация ожидает атомарный symlink `/var/www/bullet.xedoc.ru/current` на каталог конкретного релиза.
